## reference-work.md

2026-07-19 개편으로 스물한 카페 가운데 다섯이 바뀌었는데 참조 목록이 개편
이전 상태로 남아 있었다. 2권 콘셉트를 대조할 때 없는 카페와 대조하게 되므로
개편판 기준으로 다시 썼다.

- 장·부 구성을 9부 21장 개편판으로 교체했다.
- 트렌드 키워드·연대기 잠언·지역재생 인물을 개편판 원고에서 다시 뽑았다.
  걷어낸 다섯 장의 요소(성장 소비, 오래된 숲, 계절 확인 소비, 밭, 발견 소비,
  강, 안심 소비, 숨은 안뜰, 눈높이 소비, 일상)는 목록에서 뺐다.
- 마지막 장이 실로에서 피라미드로 옮겨진 것을 반영했다.
- 영어판이 개편 이전 판이라는 사실과 어긋난 여덟 장을 표로 남겼다.
