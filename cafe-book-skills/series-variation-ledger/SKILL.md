# 변주 대장

같은 악보를 스물한 번 다르게 변주하는 것이 이 책의 밀도다. 밀도가 무너지는 지점은 한 곳뿐이다. **이미 쓴 것을 다시 쓰는 것.**

열한 종류의 항목이 스물한 장에 걸쳐 있으면 관리할 값이 이백 개를 넘는다. 기억으로 감당할 수 없고, 실제로 중복이 발생했다. 이 스킬은 그것을 기계로 막는다.

## 세 단계 프로토콜

**조회 → 예약 → 확정.** 이 순서를 지키는 것이 이 스킬의 전부다.

```bash
# 대장이 없으면 만든다. --seed는 1권의 기존 값을 함께 넣는다
python3 scripts/variation_ledger.py init --seed

# 1. 조회 — 쓰려는 값이 겹치는지 본다. 겹치면 종료 코드 1
python3 scripts/variation_ledger.py check trend_keyword "빈 그릇 소비"

# 2. 예약 — 집필을 시작하기 전에 자리를 잡는다
python3 scripts/variation_ledger.py reserve trend_keyword "빈 그릇 소비" --chapter 22

# 3. 확정 — 원고에 실제로 쓰인 값을 확정한다
python3 scripts/variation_ledger.py commit --chapter 22
```

**조회는 쓰기 전에 한다.** 쓰고 나서 확인하면 이미 늦다. 중복이 발견된 키워드를 중심으로 문단 하나가 이미 세워져 있으면 문단째 다시 써야 한다.

**예약과 확정을 분리하는 이유.** 집필 중에 더 좋은 값이 떠올라 예약값을 버리는 일은 흔하다. 문제는 버린 사실을 대장에 알리지 않는 것이다. 확정 단계가 원고와 대장을 맞춘다.

```bash
python3 scripts/variation_ledger.py report --chapter 22   # 그 장의 값과 빈 항목
python3 scripts/variation_ledger.py release --chapter 22  # 예약 취소
python3 scripts/variation_ledger.py fields                # 항목 목록
```

## 병렬 집필의 충돌 방지

여러 장을 동시에 쓸 때 각 장이 독립적으로 값을 고르면 서로 같은 값을 고른다. 각자는 대장을 조회했으므로 각자에게는 문제가 없어 보인다.

**집필은 병렬로, 대장은 직렬로.** 지휘하는 쪽이 병렬 작업을 시작하기 전에 각 장의 값을 미리 예약해서 나눠 주고, 집필이 끝난 뒤 한꺼번에 확정한다. **집필 중인 하위 작업이 대장을 직접 쓰게 하지 않는다.**

## 글자가 아니라 발상을 본다

**"고요 소비"와 "정적 소비"는 다른 말이 아니다.** 독자는 글자가 아니라 발상의 반복을 느낀다.

스크립트는 뜻 묶음 검사로 이런 쌍을 잡는다. 고요·정적·침묵·적막이 한 묶음이고, 느림·천천·더딤이 한 묶음이며, 비움·빈·여백이 한 묶음이다. 같은 묶음의 말이 같은 접미와 붙으면 중복으로 판정한다.

**그러나 기계는 뜻 묶음에 없는 겹침을 잡지 못한다.** 스크립트가 통과시켰다고 안심하지 않는다. 조회 결과를 받은 뒤 스스로 한 번 더 묻는다. **이 키워드가 가리키는 손님의 행동이 앞선 장의 어떤 키워드가 가리키는 행동과 같은가.** 행동이 같으면 이름이 달라도 중복이다.

뜻 묶음에 새 묶음을 더할 필요가 생기면 `CONCEPT_CLUSTERS`에 추가한다.

## 공간명을 바꿀 때

공간의 이름이나 콘셉트를 교체하면 그 공간을 언급하는 다른 장, 부 도입, 차례까지 함께 갱신해야 한다. 놓치면 옛 이름이 원고에 남는다.

```bash
python3 scripts/variation_ledger.py rename-impact --from 카브 --to 풀 --scan manuscript/
```

**옛 이름은 지우지 않고 `book-state.json`의 `retired_names`에 남긴다.** 무결성 검사가 그 목록으로 잔재를 찾는다. 목록에서 지우는 순간 잔재를 찾을 방법이 사라진다.

## 대장이 없는 원고를 인수했을 때

원고를 먼저 읽어 값을 역산해 채운다. 빈 대장을 만들어 두면 게이트가 무력해진다. 각 장에서 열한 항목을 뽑아 `--chapter`를 붙여 등록하고, 등록하는 과정에서 이미 있는 중복을 함께 잡는다.
